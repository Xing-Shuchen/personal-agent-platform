# FB2080E 按页码扫描

用户说“扫描《书名》n1 to n2 页”时，将页码视为**包含两端**的闭区间；每个页码扫描一张独立 TIFF，文件名为 `page-<页码>.tif`。若页码、书名或“一次扫描是否对应一页”不明确，先澄清。默认使用 300 dpi、Color、完整扫描区域；用户指定其他参数时，以设备 `--list-options` 的实际能力为准。

使用本技能的 `scripts/scan_range.py` 调用 `$PAP_ROOT/tools/scanners/fb2080e-scan`，不要直接编造 USB 命令。脚本优先读 `PAP_ROOT`；个人安装版也可使用未跟踪的 `local-root.txt`。输出写入该仓库忽略的 `var/scans/books/`，每次建立唯一会话目录；保留 CLI 的 TIFF、命令、退出码和检查日志。不得覆盖已有图像、上传书页或把书名/序列号写进仓库跟踪文件。

启动前运行脚本的 `--dry-run`，核对书名、页码范围、页数、DPI、模式和 4 秒翻页间隔。扫描请求本身授权扫描；若用户尚未说明现场准备情况，只确认**第一页已放好且能够在每次扫描完成后的 4 秒内翻页**。说明扫描会驱动机械部件；准备好后一次启动，过程不要求逐页按键。若用户需要更长时间，用 `--delay-seconds`。异常机械声时让用户停止操作。

示例（在技能目录下）：

```bash
python3 scripts/scan_range.py --book '书名' --from-page 12 --to-page 18 --dry-run
python3 scripts/scan_range.py --book '书名' --from-page 12 --to-page 18
```

脚本按顺序逐页调用单张 CLI，前一张成功后才开始下一张的翻页倒计时；任何页失败或被中断时立即停止，保留已完成页和失败日志。扫描后核对 `session.json` 中的完成页码、每页的 CLI 退出状态及 TIFF 文件；报告实际完成范围、会话目录和未目视验证的部分。不要把仅有文件或命令返回 0 当作画面内容正确；用户可检查图像。连续扫描未经过真实多页验证时，明确说明此限制。重复运行若产生多个会话目录，只有核对页码齐全、图像哈希及正式目录的文件后，才清理冗余中间会话；不要删除唯一副本。
