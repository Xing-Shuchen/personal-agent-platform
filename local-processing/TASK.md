# 划线纸书照片的本地图像处理：探索目标

详细实现与验收以 [local-processing-spec.md](local-processing-spec.md) 为准；本文保留最初的三步目标摘要。

## 目标

给定一组纸书照片和对应版本的 EPUB，在本机提取**照片中实际画了下划线的印刷文字行**，把相邻的划线行合组，输出每组的位置、OCR 与 EPUB 标点扩展文本。处理顺序为：页面转正及校斜 → 分割划线行 → 合组与 OCR → EPUB 对齐和标点扩展。另行保存手写批注的独立证据。

## 三个任务

1. **分割**：在每张照片中找出有下划线的印刷文字行，并给出该行在原图中的坐标。只需分出整行；本阶段不要求精确到被划线的单个字，也不处理没有下划线的正文。
2. **OCR**：对分出的每一行识别印刷文字，保存原始 OCR 结果及其图像位置。跨行的同一段划线仍保留逐行结果，便于回看照片。
3. **EPUB 对齐与扩展**：用整行 OCR 定位 EPUB，再由红线覆盖的文字区间向两端扩展，优先到句号、问号、叹号；若只找到逗号、顿号等句中标点，输出不含末尾句中标点。保留照片 OCR 与 EPUB 文本各自的来源。EPUB 补全可以包含照片外文字，但不能反过来决定哪些行被选中。
4. **手写批注**：把目视圈定的手写区域作为独立裁图保存，尝试 OCR，并把未经核实的猜测明确标为待人工核对；手写文字不使用 EPUB 校正。
5. **角括号标记**：记录手画 `「」` 的两个端点及跨行范围；作为另一种标记进入同一组级 OCR、EPUB 对齐和标点扩展流程，并用 `mark_type` 区分下划线。

## 输出与验收

每组结果至少包含：原图文件名、成员行及坐标、单张文字与划线证据裁图、原始 OCR 文本、EPUB 匹配区间与标点扩展文本、匹配状态。无法可靠对齐时保留 OCR 和原图坐标，并标记为待核对。

用 `local-processing/` 中的照片和 EPUB 做探索样本，人工逐图核对：有下划线的行是否都被找到，未划线行是否被误收，校正后的每个字是否能在该照片行中找到视觉依据，以及每条结果能否通过坐标回到原图。先记录这些错误和失败案例，再决定可用于正式流程的准确率门槛。

本阶段只验证本地图像处理方法；知识卡片和 Obsidian 导出不在这个任务内。
