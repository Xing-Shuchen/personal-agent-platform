# Monthly synthesis

Use weekly summaries as child sources. Describe durable processes and changes
rather than concatenating weekly prose.

`next_level_digest` for this level: roughly 400-900 Chinese characters — a soft target, not a quota. It is what the level above will read instead of this summary, so it must keep the major state transitions, decisions, thread lifecycle changes, inflection points and unresolved issues, and drop incidental detail. A digest that only shortens the overview has compressed nothing.
