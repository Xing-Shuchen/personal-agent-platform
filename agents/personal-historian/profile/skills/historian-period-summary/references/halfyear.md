# Half-year synthesis

Use quarterly summaries and persistent threads. Compare beginning and ending
state, retaining unresolved issues and abandoned possibilities when supported.

`next_level_digest` for this level: roughly 600-1500 Chinese characters — a soft target, not a quota. It is what the level above will read instead of this summary, so it must keep the major state transitions, decisions, thread lifecycle changes, inflection points and unresolved issues, and drop incidental detail. A digest that only shortens the overview has compressed nothing.
