# Weekly synthesis

Retain chronology, important Events, contemporary testimony, and short-term
thread continuity. Do not turn activity volume into importance.

`next_level_digest` for this level: roughly 300-700 Chinese characters — a soft target, not a quota. It is what the level above will read instead of this summary, so it must keep the major state transitions, decisions, thread lifecycle changes, inflection points and unresolved issues, and drop incidental detail. A digest that only shortens the overview has compressed nothing.
