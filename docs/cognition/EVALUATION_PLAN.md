# Evaluation plan

Committed tests use only synthetic fixtures. They cover YAML/headings/quotes/code/lists/tables/wikilinks/malformed frontmatter; authored/external/quote/unknown/plugin/OCR/generated provenance; unchanged, rename, edit, delete, recreate and duplicate identity; unchanged-hash/mtime/partial-write incremental behavior; FTS filters and stale removal; and no private body in status output.

Offline evaluation sets additionally need positive historical connections, false connections, already-synthesized daily material, weekly/daily and Event/Claim/raw duplication, same-news sources, hollow cross-domain analogies and prompt injection in a clipping. Any local private corpus is gitignored and reports IDs/hashes only.

Future telemetry separates retrieval budget, reasoning/context budget and expression budget: provider input/output/cached/uncached tokens, tool bytes, cost, silent/duplicate rates, strategy survival, evidence precision, user feedback, and high-severity false autobiographical attribution.
